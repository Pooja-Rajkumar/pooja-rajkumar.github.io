Active project · RescueThread

Helping shelters see each dog's full story.

While volunteering with Muttville Senior Dog Rescue, I saw how behavioral notes, foster updates, and medical context can end up scattered across different tools. I built a working prototype called RescueThread that brings these records into one searchable timeline for each dog.

I'm now talking with other shelters to understand whether they experience similar challenges—and what a useful solution would actually look like.

What drives my work
01

Start with people

I find people to be endlessly fascinating, which empowers me to have a deeper understanding of what the actual pain points folks struggle with. I want to build a painkiller, not a vitamin.

02

Build, then learn

I like to jump into building something as soon as possible. For me, prototypes are a way to start conversations, test assumptions, and discover what actually helps.

03

Beginners Mindset

I'm the first to admit when I don't know something, but also the first to work at figuring it out. My curiosity has driven me to all sorts of amazing and interesting places so if you are working on something cool, I'd love to learn about it

Conference abstract · useR! 2016

Rectools: An Advanced Recommender System

Pooja Rajkumar and Norman Matloff · University of California, Davis

Our conference abstract introduces rectools, an R package for recommender systems. It describes combining methods like nearest neighbors and matrix factorization with additional information about users and items, and support for parallel computation.
